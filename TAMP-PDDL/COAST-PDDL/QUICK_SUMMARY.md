## 🎓 What You Learned

### **About the Paper (VIZ-COAST):**
- Uses Vision-Language Models to identify geometric constraints **before** planning
- Dramatically reduces planning time by avoiding infeasible branches
- Combines VLM spatial reasoning with COAST TAMP algorithm
- Submitted to ICRA 2026

### **About the Repository:**
- Production-ready implementation of COAST + RLBench
- Modular architecture with clear separation of concerns
- Pluggable planner interface (Fast Downward, LLM, etc.)
- Easy to extend with new tasks/planners/streams/actions

### **Key Technical Concepts:**
1. **Streams:** Generate geometric parameters (grasps, poses, trajectories)
2. **Actions:** Execute plans in simulation
3. **World:** Interface to RLBench/PyRep
4. **Config:** Centralized settings management
5. **Planners:** Abstract interface for task planning

### **Architecture Patterns:**
- Factory Pattern (for creating objects)
- Strategy Pattern (for swapping planners)
- Dependency Injection (no global state)
- Dataclasses (for configuration)
- Object-Oriented Design (streams/actions as classes)

## 💡 Key Design Decisions in Their Code

### **1. No Global State**
```python
# Your code:
ENV = RLBenchKitchenEnv()  # Global

# Their code:
world = RLBenchWorld.from_task_name()  # Instance
# Passed to functions/classes via dependency injection
```

### **2. Classes Over Functions**
```python
# Your code:
def fn_sample_motion(q1, q2):
    return ENV.plan(q1, q2)

# Their code:
class SampleMotion(Stream):
    def __init__(self, world):
        self.world = world
    def sample(self, inputs, fluents):
        return self.world.plan(...)
```

### **3. Abstract Interfaces**
```python
# Your code:
# Direct planner calls

# Their code:
class TaskPlanner(ABC):
    @abstractmethod
    def plan(self, ...): pass
    
# Easy to swap planners!
```

### **4. Configuration Management**
```python
# Your code:
domain_pddl = "pddl/domain.pddl"  # Hard-coded

# Their code:
@dataclass
class CoastConfig:
    task_name: str
    def __post_init__(self):
        self.domain_pddl = f"{TASK_PDDL_FOLDERS[self.task_name]}/domain.pddl"
```

### **5. Factory Functions**
```python
# Your code:
# Manual object creation

# Their code:
def get_streams(world):
    return [SampleGrasp(world), SampleMotion(world), ...]

def get_actions(world):
    return [Pick(world), Place(world), ...]
```
