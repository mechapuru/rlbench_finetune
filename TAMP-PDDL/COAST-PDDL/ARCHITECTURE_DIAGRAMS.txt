10. EXECUTION FLOW
================================================================================

    $ python run.py --task LongHorizonGrillTask --execute
    
    1. Parse Arguments
       └── task="LongHorizonGrillTask", execute=True
    
    2. Load Configuration
       └── CoastConfig.from_task("LongHorizonGrillTask")
           └── Sets domain.pddl, problem.pddl, streams.pddl paths
    
    3. Initialize World
       └── RLBenchWorld.from_task_name("LongHorizonGrillTask")
           └── Creates RLBench environment
           └── Loads task
           └── Discovers objects
    
    4. Create Planner
       └── create_planner(config)
           └── FastDownwardPlanner() or LLMPlanner()
    
    5. Planning Phase
       └── run_coast_planning(world, config, planner)
           ├── Get streams: get_streams(world)
           ├── Get actions: get_actions(world)
           ├── Call coast.plan()
           │   ├── Task planning (symbolic)
           │   ├── Stream sampling (geometric)
           │   └── Constraint checking
           └── Return plan
    
    6. Execution Phase (if --execute)
       └── execute_plan(world, plan)
           ├── For each action in plan:
           │   ├── Extract inputs/outputs
           │   ├── action.execute(inputs, outputs)
           │   ├── Update simulation
           │   └── Check success
           └── Report completion
